TR-069 (CWMP) Loading…

TR-069 lets an Auto Configuration Server (ACS) — normally your ISP's — manage this device remotely. The client is the vendor's cwmpClient. Point it at your own ACS, or turn it off to stop remote management.

This firmware has no /bin/cwmpClient, so there is no TR-069 client to configure.
Client
TR-069 daemon
Runs cwmpClient on boot and after Apply. Off stops it and keeps it from starting.
Enable CWMP
The device's EnableCWMP parameter. When off the client stays running but does not contact the ACS.
ACS
Must start with http:// or https://.
Periodic Inform
Contact the ACS on a timer, not only when it asks.
Connection Request

How the ACS reaches this device to start a session. Leave username and password empty if your ACS does not authenticate connection requests.

The CWMP WAN ACL is enabled on this device. It limits which source addresses may send Connection Requests; its entries can't be edited from this page.
On Apply: changed values are written to flash (mib commit) and cwmpClient is restarted (only if something changed). Restarting makes the device open a new session with the ACS. If your ISP's ACS is replaced or the client is turned off, the ISP can no longer manage or provision this device remotely.
