Boot Partitions Idle
This device does not expose a dual-image (A/B) layout, so there is nothing to manage here.
Running firmware—
The bootloader keeps two firmware slots. Make default changes which slot boots normally. Boot once tries a slot a single time with the watchdog armed — if it fails to come up, the next boot returns to the default slot. Boot once & keep does the same but promotes the slot to default if it boots cleanly. Changes apply on the next reboot.
Download firmware from a URL
Fetches a Realtek Luna firmware .tar (uImage + rootfs + md5.txt) over HTTPS onto the device, verifies it, then writes it to the inactive slot. To use a file from your computer instead, use Firmware Upload.
