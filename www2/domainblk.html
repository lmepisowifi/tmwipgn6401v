Master switch for this feature. Off immediately removes every blocked domain's iptables rules (the list below is kept, just not enforced); On immediately re-applies all of them — no reboot needed either way.
Block a Domain
Blocked domains are dropped at the DNS level (UDP + TCP port 53) and persist across reboots. Changes take effect instantly — no restart needed.
⚠️ This only works for clients that use this router as their DNS server. A device set to an external resolver (e.g. 1.1.1.1 or 8.8.8.8) bypasses the block entirely, since its DNS queries never pass through the router to be matched.
